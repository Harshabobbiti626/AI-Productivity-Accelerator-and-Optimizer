# ENTERPRISE TEMPLATES LIBRARY

Standardized, human-grade engineering templates ready to be used or generated by AI assistants across any stack.

---

## 📋 TEMPLATE CATALOG

| Template File | When to Use | Key Sections |
| :--- | :--- | :--- |
| **[`ADR_TEMPLATE.md`](./ADR_TEMPLATE.md)** | Documenting significant technical decisions (e.g. database choice, framework migration, event broker). | YAML Frontmatter, Decision Drivers, Evaluated Options Matrix, Trade-offs, CI Guardrails, Reversal Triggers. |
| **[`PRD_TEMPLATE.md`](./PRD_TEMPLATE.md)** | Authoring a new feature brief or Product Requirements Document. | YAML Metadata, Baseline/Target KPIs, Scope Boundary Matrix, NFRs (p99 latency, SLOs), Telemetry Plan, Canary Rollout. |
| **[`STATE_TEMPLATE.md`](./STATE_TEMPLATE.md)** | Initializing a new project's living situational awareness ledger (`.agents/STATE.md`). | YAML Metadata, Tech Stack Invariants, Environments & Health Endpoints, Milestone Backlog, Active Spikes & Debt. |
| **[`USER_STORY_TEMPLATE.md`](./USER_STORY_TEMPLATE.md)** | Authoring INVEST-compliant backlog items with BDD acceptance criteria. | YAML Metadata, DoR Gate, Scope Boundaries, 5-Scenario BDD, 10-Point DoD Checklist, Rollback Strategy. |
| **[`API_CONTRACT_TEMPLATE.md`](./API_CONTRACT_TEMPLATE.md)** | Defining RESTful API endpoints adhering to RFC 7807 error semantics. | OpenAPI 3.1 Metadata, Cursor Pagination, Headers, Success Payload, RFC 7807 (401, 403, 409, 422, 429, 503), MSW Stub. |
